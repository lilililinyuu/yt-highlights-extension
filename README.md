# YouTube 高光时刻（浏览器扩展）

汇总评论区时间戳、生成直播回放聊天的"笑点曲线"，点击即可跳转视频对应时间；
支持 AI 总结（可追问）、字幕/封面下载、进度条曲线叠加等。

## 当前进度：v1.1.50

- manifest.json（MV3，`<all_urls>` 主机权限 + `unlimitedStorage`：聊天/总结缓存不受 10MB 配额限制）+ 双 content script（MAIN world 桥 + 隔离世界主逻辑）
  + 聊天 iframe 采集脚本 + 进度条叠加层脚本
- 右侧边栏（Shadow DOM）：时间戳 / 笑点曲线 / 笔记 / 总结 / 设置 五个 Tab（宽度不足时自动加宽面板，
  日语等长标签语言也完整显示），可拖拽调宽、可折叠、
  全屏自动隐藏、深浅双主题、三语界面（中/英/日全覆盖，含审计脚本 `.diag/i18n-audit.js`）
- **评论时间戳**：Innertube 接口全量拉取（网络瞬断自动重试 2 次，失败才转 DOM 兜底）+ DOM 观察兜底（全自动滚动加载）；
  楼中楼回复任意层级全采集（commentViewModel 形态 + mutations 兜底扫描 + 多页回复续页）；
  三级时间戳来源；多时间戳评论按相关片段切分（末尾时间戳只取所在行，隔段正文不带入）；
  行首标记行（"∟"/"★"/"●" 等单独成行的符号）保留并前缀到对应时间戳的描述开头；
  时间戳所在段落里、时间戳行之前的说明行（如 "●話題を変えよう" 小节头）也归属该时间戳；
  全文详情限高内滚，展开自动定位到对应时间戳行并短暂高亮；
  当前位置行自动跟随（琥珀色高亮居中，手动滚动暂停 10s，跳转恢复）；
  各 Tab 记住滚动位置；工具条吸顶 + 「⬆ 顶部」「⌖ 当前位置」常驻按钮
- **笑点曲线**：直播回放聊天全量采集（**默认关闭**——在「笑点曲线」页点「▶ 开始采集」手动开启，
  长视频防止内存/流量开销；可随时停止，中断保留进度可续采。token 多路径定位 + 页面聊天请求捕获兜底；
  翻页上限 4000 页，覆盖 8h+ 超长回放），
  文本关键词 + 会员 emoji（手动标记优先/名称模式兜底）判定发笑；
  双折线图（粉=笑点、蓝=留言，圆点标记、共享刻度、hover 提示、点击跳转、图例点击显隐）；
  会话缓存（手动开启后即时加载，可一键清除本视频缓存）；
  表情标记列表默认收起可展开，设置区以徽章形式查看全部手动标记
- **进度条曲线叠加**：鼠标悬停视频进度条时，时间轴上方浮现半透明迷你曲线
  （粉=笑点、蓝=留言，与面板图例显隐同步）；时间戳圆点独立于曲线映射到基线
  （未采集聊天时也可单独显示，时长取自播放器），
  悬停圆点显示时间戳说明（曲线开关开启时上方另附时段条数），说明里的换行逐行显示，
  悬停其他位置显示该处时间（仅圆点模式下同样生效，不画当前位置虚线与悬停指示线，
  避免与原生进度条自带指示重叠出重影）；
  圆点开关开启时，叠加层显示期间自动保留 YouTube 自带的「重放最多」热力图
  （仅曲线模式——叠加层接管指针后热力图不消失）；
  仅圆点模式下叠加层不拦截指针：原生悬停预览（缩略图/时间）照常工作，
  悬停圆点时其说明文字显示在原生预览卡下方（整卡自动上移让位，不与时间/进度条重叠），
  说明保留原始换行不自动折行，:表情快捷名: 渲染成表情图片；
  点击/拖动面板直接跳转对应时间；开关、深色背景/折线透明度分离可调
  （调节时自动在进度条处预览），全部本地持久化
- **笔记编辑器**：⏱ 插入时间戳（暂停可开关）、【节】/└ 小节/缩进/减缩进 结构化编辑、
  ★ 重点标记（符号可自定义）、按视频自动保存、一键复制
- **时间戳勾选导出**：逐行勾选 + 全选，按时间顺序复制 `时间　说明`
- **AI 总结**：接入自定义大模型（OpenAI 兼容 + Anthropic 双协议自动识别，
  服务商预设下拉自动填端点/模型示例；`<all_urls>` 权限下任意 LLM API 不受 CORS 限制），
  综合字幕 + 评论时间戳 + 聊天高能生成「总结 + 分时间段 + 网络用语/术语说明」；
  输出语言三语严格整篇输出（三语提示词模板，标题不混语言）+ 自定义要求；
  直播类型预设（自动判断/杂谈/游戏/联动/歌回/其他，按类型切换总结侧重点）；
  术语数量上限可选（网络用语/专业术语最多列出几条，留空不限）；
  输出长度不设硬上限（Anthropic max_tokens 16384 起，模型不支持时自动降级重试）；
  结果按视频缓存（最近 20 个，可一键清除），输出下方常驻 AI 生成免责声明；
  **追问**：优先基于已总结内容回答；总结没有的信息自动回退到原始素材
  （自动字幕原文 / 评论时间戳 / 聊天高能节选）；问题中提到时间点时
  自动注入该时段的字幕原文（支持"逐句翻译某片段"类问题）；
  无总结也可直接追问；携带最近 6 轮对话，回答内时间戳可点击跳转；
  **追问历史持久化**：按视频保存（最近 20 个，刷新/重开浏览器后可继续追问），
  支持一键清空本视频对话，重新生成总结后自动重置
- **字幕下载（SRT）**：yt-dlp 同款原理——多源获取字幕轨道（页面 ytInitialPlayerResponse → 页面
  /player 响应捕获 → 直连 /player 接口（WEB→内嵌/安卓客户端轮替）→ watch 页 HTML 兜底，
  规避 PO Token 降级），下载时借用播放器自己的 PO Token 与请求参数
  （优先重放捕获的完整请求，8h+ 长视频也完整；捕获缓存带 10 分钟新鲜度门控）+
  `fmt=json3`/`vtt`/XML 三格式回退转 SRT；
  AI 总结字幕走同一条链路；旁有**封面下载**（maxres→sd→hq 自动降级，JPG）
- **悬浮球**：⏱ 入口球可上下拖动并记忆位置，点击打开面板；悬停右上角浮现小 ×（或右键）可移除
  （点击浏览器工具栏扩展图标恢复，点击图标同时开合面板）
- **面板布局**：吸附模式高度可拖拽（底部边缘）；自由模式下位置/宽高任意放置
  （左缘拖拽固定右缘伸缩宽度），透明度、背景模糊度可调，「锁定面板位置」防误触，
  一键重置默认布局；宽高与位置记忆——首次开启默认位于距页面右侧 200px 处，
  拖动后取消/重新勾选或刷新页面均回到上次状态
- **设置**：主题切换、发笑关键词自定义（与内置规则叠加）、手动标记表情徽章查看、
  笔记重点标记符号、时间轴叠加开关/透明度/圆点开关
- 面板内键盘事件不再触发 YouTube 播放器快捷键（方向键/空格）

## 加载方式（Chrome / Edge 通用）

1. 打开 `chrome://extensions`（Edge 为 `edge://extensions`）
2. 打开右上角/左侧的「开发者模式」
3. 点「加载已解压的扩展程序」，选择本目录（`extension/`）；更新代码后点扩展卡片上的 ↻ 重新加载
   （若弹出"新增权限"提示，需点允许）
4. 打开任意 YouTube 视频页，页面右侧出现 ⏱ 悬浮球（可上下拖动），点击展开边栏

## 已知边界

- 新版"页内回放聊天"A/B 布局下，全量快取依赖聊天 iframe / 页面请求捕获的 token
  （接口直连被服务端 404 门控）；已有兜底链：iframe token → 桥读页面数据 → 捕获页面聊天请求自愈
- 超长视频（8h+）的回放聊天翻页上限为 4000 页（约 30h+ 内容），正常够用；
  中断时保留进度与续页 token，下次打开自动增量续采（token 过期则需重采）
- DRM 内容（电影/剧集）的字幕与媒体数据受 Widevine 保护，无法采集
